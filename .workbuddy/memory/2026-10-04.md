### psycopg2 / psycopg3 踩坑合集（重要）
- psycopg 原生 `connect()` 只认 `postgresql://`；`postgresql+psycopg://` 是 SQLAlchemy 语法，
  传给 psycopg 会 `ProgrammingError: missing "=" after ...`。
- SQLAlchemy 侧必须写 `postgresql+psycopg://`；写 `postgresql://` 会走 psycopg2 驱动 → `No module named psycopg2`。
- psycopg3 默认隐式事务：`DROP/CREATE DATABASE` 需 `autocommit=True`（否则 ActiveSqlTransaction）。
- `create_all()` 前必须 import 模型模块（app.models / models_ontology / models_ai），
  否则 metadata 为空 → **「静默成功但 0 张表」**（踩了，表数显示 0）。
- `alembic/env.py` 依赖 psycopg2、环境是 psycopg3 → **`alembic upgrade head` 当前不可用**，
  暂用 create_all 顶替。这是新环境冷启动的 P2 债，已记入 README 已知限制。
- run_tests 解析各脚本输出时 findall 分组是 str，必须 `int()`，否则汇总 `+=` TypeError。
