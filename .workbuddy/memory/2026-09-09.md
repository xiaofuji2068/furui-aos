| 项 | 结果 |
| --- | --- |
| 依赖 | `next/react/react-dom/typescript` 全部 OK，node v22.22.2，`node_modules` 91 个包目录 |

| 路由 | `app/admin/[slug]/page.tsx` 存在；`app/admin/page.tsx` **不存在**（访问 `/admin` 会 404，访问 `/admin/{data,integration,...}` OK） |
| 探活（3000） | **所有路由返回 000（连接超时）/ 502** |
| 日志 | `frontend.log` 第 39-120 行被 `Jest worker encountered 2 child process exceptions` + `Error: write EPIPE` 刷屏 |

#### 根因
**Next.js dev server 的 RSC worker 全死**（不是后端问题，是 dev 自身 worker 进程 EPIPE 死掉，新的请求来了 worker 起不来，连接挂起到 5s/8s 超时返 000，少数情况 Next 反代层返 502）。
- `frontend.log` 多次出现 `page: '/admin/data' /admin/integration /admin/permission /admin/model`，RSC worker 全部失败
- 这是 dev server 长跑 + Windows EPIPE 经典现象，**不影响生产 build**，重启 `npm run dev` 通常可恢复

#### 前端其他问题
1. **`app/admin/page.tsx` 不存在** — 访问 `/admin` 会 404；现在 admin 入口是从侧边栏跳到 `/admin/xxx`，但缺一个总览页
2. **`/api/api/data-sources` 多重路径** — 后端日志抓到过 1 次，前端某处 baseurl 拼多了一次 `/api`，扫一遍前端的 API 常量
